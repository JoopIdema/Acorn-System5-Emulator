Acorn System 5 Emulator version 1.4.0 (web)

Browser version of the Windows emulator, same emulation core. For private and hobby use.

Machine models

Custom System 5IMADOS 1.41, 40x25 teletext, SID 6581, BBC BASIC II at &A000-&DFFF, 1 MHz
Standard System 5AcornDOS, 40x25 teletext or 80x25 mono VDU, System BASIC at &C000, optional floating point ROM at &D000, CPU 1 or 2 MHz, no SID. Start BASIC with the button (types GO C2B2). Floating point: use FPRINT instead of PRINT.

Keys

F9Break
Shift+F9Space-Break (boots the disk)
F8Smoothing on/off
Caps LockUppercase on/off (on at start; Shift inverts)
Ctrl+VPaste text as typing
Cursor keysCtrl-A / Ctrl-S / Ctrl-W / Ctrl-Z. End = Ctrl-Q (copy). Backspace = DELETE.
Click the picture first so the keyboard goes to the emulator. Browsers keep some shortcuts for themselves (for example Ctrl+W closes the tab), so use the cursor keys.

Disks

Use Mount… or drop a .ssd file on the picture (hold Shift for drive 1). Changes written by the emulated machine are kept in this browser (IndexedDB) and survive a page reload. Use Download to save a disk as a .ssd file. Reset saved data forgets all settings and disk changes.

Credits

Teletext font and character rounding and the SID emulation (reSID-fp) come from b-em (GPL). The ROMs and disks are embedded for private use. The monitor frame is a Microvitec Cub (image supplied by the user); switch it off with the Monitor frame checkbox.
